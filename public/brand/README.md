# The Chatbot brand

Every brand asset of The Chatbot. They are generated in [barro-theme](https://github.com/irwinarruda/barro-theme/blob/main/BRAND.md), which documents the lettering and its spacing, and copied here: use them as they are, and never redraw, recolor or edit them. The `o` is a round speech bubble with a small tail cut at 60°, like the letters. The bubble is always Barro's brick, `#B64D3F`.

`favicon.ico`, the slate tile at 16, 32 and 48 px, is the one exception: it stays at the root of `public/`, because browsers ask for `/favicon.ico` by default.

| File                                          | What it is                                                         | Where it is used                                                    |
| --------------------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------- |
| `logo-dark.svg`                               | The `>chatbot` wordmark with light letters                         | The header on the dark themes, and the README in GitHub's dark mode |
| `logo-light.svg`                              | The wordmark with dark letters                                     | The header on the light themes, and the README in GitHub's light mode |
| `logo.svg`                                    | The wordmark with mid-gray letters                                 | A place that cannot pick dark or light                              |
| `mark-dark.svg`, `mark-light.svg`, `mark.svg` | The `>o` mark on a transparent background, in the same three colors | A place that puts the mark on its own background                    |
| `icon.svg`                                    | The `>o` mark, white chevron and brick bubble, on a slate tile     | The SVG favicon                                                     |
| `apple-touch-icon.png`                        | The tile at 180 px, square, because iOS rounds the corners itself  | The apple-touch icon, on iPhone and iPad home screens               |
| `icon-512.png`                                | The tile at 512 px                                                 | An app icon that needs a large PNG                                  |
| `avatar.svg`                                  | The `>o` mark on a slate square, safe for a circle crop            | The source of the avatar PNGs                                       |
| `avatar-640.png`                              | The avatar at 640 px                                               | The WhatsApp profile picture                                        |
| `avatar-120.png`                              | The avatar at 120 px                                               | The Google OAuth consent screen logo, which Google asks for at 120×120 |
| `avatar-1024.png`, `avatar-512.png`           | The avatar at 1024 and 512 px                                      | Google Chat and other profile pictures                              |
| `avatar-256.png`                              | The avatar at 256 px                                               | A small profile picture                                             |
